Rule scopes description

Rules remember a browser window size and, when enabled for that rule, its position. A rule applies when the current URL is within its scope.

About Effective scope

Effective scope shows only the part of an address that actually participates in matching. A path, parameter, or fragment that does not matter to the selected scope is omitted. For “This domain and its subdomains”, www.example.com becomes example.com; the new “Domain with and without www” uses that same base value but covers only example.com and www.example.com. “Exact hostname” retains www.example.com.

This domain and its subdomains
A rule made for https://library.silverpine.example/ also covers https://catalog.library.silverpine.example/books, but not https://other.silverpine.example/.
Domain with and without www
A rule made for https://library.silverpine.example/ covers library.silverpine.example and www.library.silverpine.example, but not catalog.library.silverpine.example.
Exact hostname
A rule made for https://library.silverpine.example/ covers that hostname only, not www.library.silverpine.example or catalog.library.silverpine.example.
This URL and its subpaths
A rule made for https://library.silverpine.example/guides covers https://library.silverpine.example/guides/start, but not https://library.silverpine.example/guide.
This URL — any parameters
A rule made for https://library.silverpine.example/search covers both https://library.silverpine.example/search?q=maps and https://library.silverpine.example/search?page=2.
This URL — exact query parameters
A rule made for https://library.silverpine.example/search?q=maps&type=atlas covers the same two parameters in either order, but not a URL with an extra or missing parameter.
This URL — non-exact query parameters
A rule made for https://library.silverpine.example/search?q=maps covers https://library.silverpine.example/search?q=maps&page=2, but not https://library.silverpine.example/search?q=stars.

Scopes can overlap. When more than one rule covers the current URL, SmartWindowSize applies the narrowest rule: exact query parameters, non-exact query parameters, any parameters, URL and its subpaths, exact hostname, domain with and without www, then domain and its subdomains.
